# SentimentAgent

## 职责

从财经新闻、社交媒体（雪球、X/Twitter）等来源抓取与特定股票/行业相关的内容，进行情绪分析，输出情绪评分、趋势和关键事件时间线。

---

## 输入（Input）

```json
{
  "stock_code": "600519",
  "stock_name": "贵州茅台",
  "industry": "白酒",
  "lookback_days": 30,
  "sources": ["news", "xueqiu", "twitter"],
  "include_macro": true
}
```

---

## 输出（Output）

```json
{
  "stock_code": "600519",
  "sentiment_score": 65,
  "sentiment_label": "偏正面",
  "trend": "改善",
  "breakdown": {
    "news": { "score": 70, "article_count": 42 },
    "social_media": { "score": 58, "post_count": 1200 },
    "macro": { "score": 62, "summary": "货币政策宽松预期上升，有利消费板块" }
  },
  "key_events": [
    { "date": "2026-04-15", "type": "正面", "event": "一季报净利润超预期 15%", "impact": "高" },
    { "date": "2026-04-10", "type": "负面", "event": "传公务消费限制政策讨论", "impact": "中" }

}
```

## 数据来源

| 来源 | 获取方式 | 覆盖内容 |
|------|---------|---------|
| 财经新闻 | AKShare `stock_news_em` | 东方财富个股新闻 |
| 雪球 | AKShare `stock_xueqiu_hot_follow_xq` / 爬虫 | 社区讨论、持仓人数 |
| X/Twitter | Twitter API v2 或第三方聚合 | 海外视角、做空机构 |
| 宏观政策 | AKShare `macro_china_pmi_mfg` 等 | PMI、CPI、货币政策 |

## 核心逻辑/算法

### 1. 情绪打分流程

```
原始文本
  → 文本预处理（去广告、去重）
  → LLM 情绪分类（正面/负面/中性，0–100 分）
  → 按来源、时间加权汇总
  → 输出综合情绪分
```

### 2. 加权规则

- 新闻权重高于社媒（新闻更可信）
- 近 7 天权重 > 7–30 天（时效性衰减）
- 重大事件（财报、重组公告）单独标注，不纳入均值

### 3. 关键事件识别

LLM 从新闻列表中识别：
- 财报发布（超预期/不及预期）
- 监管/政策事件
- 机构增减持
- 行业重大变化

### 4. 情绪趋势判断

对比本周 vs 上周平均情绪分：>5 为"改善"，<-5 为"恶化"，其余"持平"

## 与其他 Agent 的交互

- **依赖**：DataFetcherAgent（新闻数据）
- **被依赖**：OrchestratorAgent（汇总报告）

---

## Prompt 设计要点

- 每批新闻以列表形式传入（每条：标题 + 摘要 + 日期），单次最多 20 条
- 要求 LLM 对每条打分并给出 1 句理由，避免模糊输出
- 宏观情绪分析需提供具体数据（如 PMI 值、利率变化），不能只问"宏观怎么样"

---

## 示例

**用户请求**：最近市场对茅台的看法如何？

**分析流程**：
1. 拉取近 30 天东方财富新闻（42 条）
2. LLM 批量情绪打分
3. 雪球热度数据
4. 识别关键事件：一季报超预期（+15%）、政策讨论（负面）
5. 输出：综合情绪 65 分，偏正面，近期改善
