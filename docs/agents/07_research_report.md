# ResearchReportAgent

## 职责

聚合多份券商研报，提取核心观点，识别分析师共识与分歧，输出一份清晰易读的综合研报摘要。

---

## 输入（Input）

```json
{
  "stock_code": "600519",
  "reports": [
    { "source": "中信证券", "date": "2026-04-10", "text": "全文...", "format": "text" },
    { "source": "华泰证券", "date": "2026-04-08", "file_path": "/reports/huatai_600519.pdf", "format": "pdf" }
  ],
  "max_reports": 10
}
```

`format` 支持：`text`、`pdf`（自动解析）、`url`（抓取页面）

---

## 输出（Output）

```json
{
  "stock_code": "600519",
  "report_count": 6,
  "date_range": "2026-03-01 ~ 2026-04-10",
  "consensus": {
    "rating": "买入",
    "rating_distribution": { "买入": 4, "增持": 1, "中性": 1 },
    "target_price_avg": 1780,
    "target_price_range": { "low": 1600, "high": 1950 }
  },
  "key_themes": [
    { "theme": "高端化趋势持续", "supporting_analysts": ["中信", "华泰", "国泰君安"] },
    { "theme": "国际化布局加速", "supporting_analysts": ["中信", "招商"] }
  ],
  "disagreements": [
    { "topic": "2026 年收入增速预测", "range": "8%–18%", "key_difference": "对高端白酒需求复苏节奏判断不同" }
  ],
  "earnings_forecasts": [
    { "analyst": "中信证券", "eps_2026": 62.5, "eps_2027": 72.1, "revenue_growth_2026": "15%" }
  ],
  "summary": "综合研报摘要（Markdown，约 500 字）",
  "risks_mentioned": ["消费降级", "限制三公消费", "国际化不及预期"]
}
```

---

## 数据来源

- 用户上传的研报 PDF / 文本
- （规划中）券商研报 API 或爬虫（东方财富研报、万得研报）

---

## 核心逻辑/算法

### 1. 文档解析

- PDF：使用 `pdfplumber` 或 `pymupdf` 提取文本
- 过滤免责声明页、目录页、图表说明等噪声

### 2. 结构化提取（LLM）

对每份研报，LLM 提取：
- 评级（买入/增持/中性/减持）
- 目标价
- 核心投资逻辑（3–5 条）
- 盈利预测（EPS/营收增速）
- 主要风险

### 3. 共识与分歧分析

- 统计评级分布
- 对 EPS 预测做方差分析，方差高的项目标注为"分歧点"
- LLM 解读分歧原因

### 4. 综合摘要生成

将所有研报的结构化提取结果作为 context，要求 LLM 生成：
- 综合评价（避免简单罗列）
- 突出多方共识的核心逻辑
- 点名分歧，解释不同假设
- 用散户看得懂的语言（不用"弹性"、"催化剂"等黑话）

---

## 与其他 Agent 的交互

- **依赖**：无（研报为用户直接提供）
- **被依赖**：OrchestratorAgent

---

## Prompt 设计要点

- 单次提取一份研报的结构化信息，避免一次性塞入多份研报
- 摘要生成时，以所有研报的提取结果作为 context，明确要求对比而非重复
- 禁止模型编造分析师未说过的内容，要求引用来源
- 输出字数控制：单报提取 <200 字，综合摘要 400–600 字

---

## 示例

**用户上传**：6 份茅台研报（4 中信/华泰/国君/招商买入，1 海通增持，1 申万中性）

**分析流程**：
1. 解析 6 份 PDF，提取结构化信息
2. 评级：买入 4 / 增持 1 / 中性 1
3. 目标价：1600–1950，均值 1780
4. 共识：高端化 + 国际化
5. 分歧：2026 年增速预测 8%–18%
6. 输出：综合摘要，建议参考均值目标价，关注增速分歧
